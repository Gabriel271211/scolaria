# 🗄️ Archive — ancien projet ScolarIA

Ces fichiers datent de l'ancienne idée de ScolarIA : plusieurs « modes » séparés (Langues, Sciences, Histoire, Arts…), chacun avec son propre fichier et sa propre identité visuelle.

**Cette idée a été abandonnée (octobre 2026).** ScolarIA est maintenant une seule app : `scolaria-home-v2.html`.

Les fichiers sont gardés ici pour mémoire, mais :
- ils ne sont plus liés depuis l'app (liens retirés du menu) ;
- ils ne sont **pas déployés** sur Vercel (`archive/` est exclu par `.vercelignore`) ;
- ils ne sont plus maintenus — ne pas les modifier.

| Fichier | Ce que c'était |
|---------|----------------|
| `scolaria-langues.html` | Mode Langues style Duolingo (EN/ES) : parcours zigzag, 6 unités par langue A1→B1, cours écrits, 6 types d'exercices, chat IA. Progression en localStorage `sk_lang`. |
| `scolaria-sciences.html` | Mode Sciences (Physique, SVT, Maths). |
| `SCOLARIA_FINAL.md` | Ancien plan en 10 sessions (modes Sciences, Histoire, Arts, Arène, Enquête, Oral Brevet, Mind Map…). |
| `SKILL_DESIGN.md` | Ancienne charte design « une identité visuelle par mode ». |

Pour les remettre en service un jour : les déplacer à la racine et remettre un lien dans le tiroir (`#drawer-modes`) de `scolaria-home-v2.html`.
